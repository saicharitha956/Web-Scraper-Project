# Web Scraper for Quotes

## Project Description
A Python-based web scraper that extracts quotes and author names from Quotes to Scrape using Requests and BeautifulSoup.

## Technologies Used
- Python
- Requests
- BeautifulSoup
- JSON

## Features
- Sends HTTP requests to a website.
- Extracts quotes and author names.
- Parses HTML content.
- Saves extracted information into a JSON file.
- Handles connection and HTTP errors.

## Installation

Install the required libraries:

```bash
py -m pip install -r requirements.txt
```

## How to Run

```bash
py web_scraper.py
```

## Output
The extracted quotes and authors are stored in `quotes.json`.
